# 紫薇 Android 管理 App

首个内部测试版：`com.ziwei.manager`，Android 8.0（API 26）及以上。它是现有紫薇的手机管理入口；受控手机上的 Agent / Updater 继续使用原应用，Hermes 继续在绑定的常开电脑执行。

## 安装和使用

下载本次交付的 `ziwei-manager-0.1.0-internal-code1.apk`，传到安卓手机，打开安装；系统询问时，仅为本次使用的下载或文件应用允许安装来源。安装后打开「紫薇」，登录原账号并选择原工作区。新应用只需要网络权限，不需要无障碍、设备管理员或常驻后台权限。

这是独立管理应用的内部签名，不覆盖或升级互联 Agent / Updater。后续更新管理应用须沿用同一签名；不要卸载应用来做常规升级，以免清除本机汇报队列。生产签名、应用商店发布不属于本次交付。

## 首版功能

- 员工首页：原员工头像、名称、岗位及服务器返回的运行状态，直接打开原聊天。
- 长期聊天：文字、多图、真实执行进度；已初始化 Bot 可提交既有停止请求，待电脑返回退出证据后才显示已停止。
- 听汇报：选择员工并排序 → 当前员工汇报 → 追问 → 下一位或稍后再听 → 汇总与计划待办。任务和执行记录是事实来源，没有记录明确显示暂无记录。汇报及追问保留在员工原聊天，本机只保存本次会次和顺序。
- 工作：原任务列表、说明编辑及合法状态流转；汇报中明确的下一步可经点击加入计划任务，创建本身不启动执行。
- 员工详情：名称、描述、头像编辑，以及现有 Bot 例行工作的添加、暂停、恢复和立即运行；复杂配置从「更多员工设置」进入电脑版。
- 设备互联：沿用原 Owner/Admin 终端权限，查看电脑和手机状态、最后截图与拍摄时间、显式请求新截图和放大查看。普通成员不会取得终端管理员权限。

## 数据和恢复

本地 WebView 仅拦截 `https://qzelynth.top/__ziwei_manager__/` 下打包的界面资源。`/api/` 通过原站点的 HTTPS、HttpOnly 会话 Cookie 和原权限检查访问，账号、员工、Profile/HOME、任务、会话及手机队列均沿用原系统，不需要替换正式站或迁移数据库。

前台每 8 秒及回到前台时重新读取状态；后台不执行员工任务或保持另一个调度器。普通消息的请求标识及内容摘要按账号、工作区、员工保存，断线重试保持同一 `clientMessageId`。汇报页按原执行 ID 关联回执；旧接口只暴露最新执行时，以相同消息标识和原消息体取回服务端幂等回执，不生成另一个执行。图片字节以原聊天为准，本机会次仅持久化附件元数据。

汇报顺序目前仅保存在这台管理手机；换手机不会自动同步会次。退出 App 后恢复当前会次，不能保证系统清除应用数据后的恢复。设备离线、原执行待核实、配置或权限冲突均显示真实错误，不自动启用员工、重建 Profile 或改用其他设备。

## 开发和构建

结构：`web/` 为独立移动界面 ES modules，`android/` 为 Java 原生外壳，`scripts/` 为无 Gradle daemon 的固定工具链构建脚本。`web/bot-presentation.js` 复用本次桌面版本的真实停止和执行状态规则，变更状态合同时应同步核对该模块。

```sh
node --test mobile-manager/test/*.test.mjs
node mobile-manager/test/browser-check.mjs
python3 mobile-manager/scripts/build-android.py
```

构建使用缓存内的固定 JDK、Android API 35 与 build-tools 35；脚本校验工具来源、APK 签名、zipalign、包名、版本和打包资源。输出在被 Git 忽略的 `mobile-manager/dist/`，`manifest.json` 记录源码提交和每个界面资源哈希。内部签名密钥留在本机私有缓存，不提交到 Git，不打入 APK。

浏览器验收使用真实内存 repository 和合成设备/模型回执，所有网络在 Chromium 路由中拦截，不监听端口、不访问生产账号或真实手机。它证明界面与既有数据合同的联通，不代表生产员工已跑通业务。截图和结果在 `.local/mobile-manager-qa/`。Android 模拟器的实际安装与原生验证另见本次交付记录。

如需本地监听服务，包括模拟器、ADB、调试端口和临时预览，必须先读取统一端口中心、分配或登记，再启动并检查；结束后停止并释放临时登记。不能用未经登记的服务替代本流程。

## 验收边界

本版不包含 iOS、系统推送、员工在管理手机上执行模型、互联 Android 端升级或后台常驻服务。正式账号登录、个人手机图片选择器及真实员工/手机业务仍须由实际设备回执确认。不要把浏览器夹具、编译成功或模拟器安装称为用户实机验收。
