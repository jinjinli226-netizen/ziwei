# Bot 管理入口重排

## 目标与来源

用户要求借鉴 DSH Bot 的简洁名册与宽主区，改进紫薇网页的管理入口，并明确授权向 [dsh bot 会话](codex://threads/01a180b9-516e-75d2-9f72-023bb5aeeb56) 作者请教。作者完成了只读源码对照，建议使用“左侧选员工、主区看状态、低频配置按需进入”的结构。

DSH 的绿色就绪只证明其进程存活且报告了地址，不证明模型调用成功。紫薇继续使用自身的工作区、员工、设备、Profile/HOME、当前配置检查和原生执行回执。此次不复制 DSH 的运行时、凭据实现、滚动阈值或身份模型。

本轮遵循 `ziwei-frontend-refactor` 与原版 `b-end-design-system` Skill。页面采用保留列表上下文的详情模式，主操作集中在顶栏，普通操作使用浅底按钮，选择和悬停不改变边框尺寸。

## 页面与架构

- Bot 页面默认将工作区导航收为 68px 图标栏，可展开；离开 Bot 页面恢复原导航，实际主聊天继续使用自身的 focused shell。工作区、账号、退出、语言、帮助和全站路由均保留。
- 名册仍来自同一工作区员工集合，支持真实运行时筛选和搜索；没有另建 Bot 身份或假分组。名册和详情分别滚动，顶栏与管理页签保留在详情顶部。手机或低高度屏幕使用可展开的名册，选择员工后收起，Esc 可关闭；短横屏允许名册本身滚动，不将员工列表压成零高度。
- 原 `chat` 管理路由显示为“概览”，真正的长期主聊天由顶栏按钮进入原 `main_conversation_id`。常用页签为概览、基础配置、能力配置、例行工作、运行记录；资料与工具、伙伴协作、消息与音频、主动工作通过“更多管理”和概览入口进入，原九个 section key 不变。
- 概览分别展示设备连接、实例、当前模型与配置检查、最近动作；设备发现失败或心跳不健康不显示设备在线，旧版本检查成功不显示本版配置通过，未初始化员工不声称已有独立目录。最近动作区分会话任务、配置检查和其他动作，不把检查成功冒充会话完成。保存的默认服务商和模型不冒充最近执行实际使用的模型。
- 环境授权、创建进度、Profile/HOME 明细和恢复操作放入基础配置；其余页保留阻断摘要及“处理运行环境”入口。团队管理、手机互联和删除员工移入基础配置的员工管理区，继续使用原事件和删除确认。
- 写入未知、版本冲突、强制放弃旧任务、失败终态、停止请求与进程退出证据保留原逻辑。切管理页签不重置未保存草稿，不重新创建会话，不改变队列策略。
- Codex、DSH 等非 Hermes 员工仍使用原聊天、员工设置与能力清单；不套用 Hermes 的实例就绪状态和初始化过程。员工主动回填 Skill/MCP/CLI 的现有入口继续保留。

## 验证入口与边界

`frontend/src/bot-management-view.test.mjs` 编译并挂载真实 Vue 组件，使用内存 API 边界验证管理入口和状态；`frontend/src/workspace-shell.test.mjs` 验证导航切换与全站操作。原 workbench、owned Profile、混合名册、能力清单和布局合同测试继续执行。

`frontend/verification/bot-management-preview.mjs` 使用真实组件和明确标记的示例数据生成静态预览，并通过 headless Edge 的 `file://` 页面检查布局。预览不连接线上账号、设备或模型，不启动端口服务，不使用 Computer Use。它用于视觉验收，不能证明实际模型已成功执行。

本轮为网页源码重构；正式部署、生产设备连接与真实模型调用分别验收。

## 本轮验收结果

- 真实 BotWorkbench 组件专项 **17/17**，WorkspaceShell 专项 **3/3**。全部 `frontend/src/*.test.mjs` 加现有布局合同共 **516/516** 通过，日志与实际文件集合保存在工作树 `.local/bot-manager-frontend.log`、`.local/bot-manager-frontend-files.json`。
- `npm run lint` 检查 **335** 个源码文件通过；`npm run build` 成功，保留既有入口包大于 500kB 的提示；`git diff --check` 通过。
- 原版设计 Skill 的审计脚本对两个改动组件均返回零违规，记录为 `.local/bot-manager-design.log`。该静态扫描不替代实际交互检查。
- 概览、设置、展开名册分别检查 **1440×1000、390×844、390×640、844×390、844×360**，共 **15** 帧。全页无横向溢出；最矮横屏展开列表仍有 144px，名册可滚至最后员工，创建入口可到达；名册和详情滚动互不牵引。尺寸与滚动证据在 `.local/bot-management-preview/layout-results.json`，带示例标记的截图位于同目录。
- 验收未启动业务服务、未修改线上数据、未调用真实模型或生产设备，未使用 Computer Use。底层队列、Provider 凭据通道与 CLI 执行逻辑没有在本轮改写。
