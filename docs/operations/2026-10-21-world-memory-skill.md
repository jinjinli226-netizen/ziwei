# 紫薇映界共享知识库技能

2026-10-21。用户要求将 https://world.qzelynth.top/doc/guide.md 的官方能力接入紫薇，让员工按需使用共享知识。已读取官方指南及官方CLI源码，并与既有技能执行链交叉复核。

## 接入方式

新增平台技能“紫薇映界·共享知识库”。各工作区幂等提供简明指南，员工下一轮执行与原有自选技能合并，覆盖聊天、Task、Routine、Gateway、协作及Codex队列刷新；保留人格、岗位、模型、运行绑定和原技能。只允许此固定平台目录成为默认技能，普通导入项不能通过自报defaultEnabled获得全员注入。用户卸载后不再默认注入，按名称选择的残留也不能绕过卸载；重新安装恢复。

这是随任务下发的约3.2KB使用指南，不等于给所有电脑预装CLI或给所有员工签发凭据。技能目录的installed指指南可用，integration中标明setupRequired与connectionStatus:not_verified。详细协议按需读取官方文档，不每轮注入整篇文档。不需要升级ziwei_user或手机App。

## 官方身份与权限

官方提供Node.js≥22.12的ziwei-memory CLI与本机stdio MCP，后者访问HTTPS服务；没有远程 `/mcp`。每个工作区＋员工派生稳定独立的zw档案标识，更名不变；已有受信员工档案先whoami核对并复用，不共享default或管理员凭据。首次由员工在任务允许范围调用官方 `--login --no-browser` 及独立 `--profile`，管理员在自己的网页批准返回链接，无需到员工电脑执行命令。

知识、经验、工具默认私有，用户明确要求共享时使用company范围；汇报默认公司可见，受限内容需选private或selected。company只向知识库已启用身份共享，不能由Skill绕过权限。导入MCP实际配置时将官方逻辑key `ziwei-memory` 合法映射为 `memory_world`，保留官方Node、CLI、档案路径，不放宽紫薇保留名校验或误标HTTP OAuth。

真实连接仍需检查目标电脑的CLI、whoami、工具发现与实际检索。没有发起员工任务、安装CLI、登录、签发身份、公开私人知识或调用下载资产；不能把指南注入测试写成全员已连接。
