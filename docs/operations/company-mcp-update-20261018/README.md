# 公司台式 MCP 更新的一次性维护程序

此程序只用于用户已授权的公司台式空闲客户端停止和官方升级，固定 bigtron、设备 device_11af6d85-6c5c-4cbe-9a25-31599a474e5d、原 build161cc990 及已配对用户。不是通用强停接口，不接受任意进程 PID，不改员工配置，不清空任务历史或去重记录。

已配对客户端的普通停止被维护扫描器的 ACTION_STATE_CORRUPT 汇总代码阻塞。该代码不一定表示 JSON 语法损坏；本程序不把历史记录改为成功或退出。它只验证并退出当前用户的原 daemon 根进程，然后运行既有官方更新器、显式启动并验证目标 build88b2ea9f。未知业务执行的历史证明保持原样；本次操作不宣称修复历史维护检查或未来的普通停止。

运行前需要：原安装和配置哈希、设备及全部连接、PID/创建时间/入口命令/监听归属/用户 SID/启动 nonce 一致；认证暂停接收并等当前执行、轮询、结果投递、隔离和辅助进程归零；原 daemon 无子进程；状态与投递文件双读、封存和 CAS 一致。仅用持有的 Process.Handle 结束该原实例；结束记录的 scope 为 owned-daemon-root-only，不生成业务进程树退出证明。

仓库提供可读 Node/PowerShell 源和隔离测试，发布入口自包含并绑定精确源码哈希。仅更新原来已失败的同名 Task Scheduler 任务，保留脚本、Plan 和 Task XML 备份，延后触发，不在数字员工当前执行内结束父客户端。失败不自动重复强停或安装。

静态/隔离检查与 Windows 现场运行必须分别记录；当前现场结果见上级 [本轮操作记录](../2026-10-18-bot-deferred-mcp-config.md)。
