# 紫薇 UI 与功能面收敛

本轮继续沿用 DSH Bot 的统一员工工作台，把视觉收敛和真实状态反馈补到首页、任务、自动化、日历、文档、运行时、成员、技能中心以及聊天队列。没有另起一套旧员工页面，也没有改变后端数据或执行协议。

## 功能改动

- 工作区初始读取或刷新失败会保留明确的错误条和“重试”，不会把旧数据静默当成空工作区。
- 首页“需要帮助？”现在打开工作区内的帮助中心，可直接进入开始工作、员工/设备、收件箱队列或技能中心。
- 首页、自动化、日历、文档、成员、运行时和技能页在读取期间显示真实的异步状态，并用 `aria-busy` 标识当前页面。
- 日历无事件时提供新建日程入口；文档搜索无结果时提供清除搜索；技能筛选无结果时提供清除筛选，平台目录为空时不再误称“没有匹配技能”。
- 运行时版本和启动命令属于只读元数据，改成文本展示，避免看起来像可点击但没有动作的按钮。
- 聊天和待发队列对部分投影（缺少 `items`、`count` 或暂停字段）做一次入口归一化，保留加入队列、暂停、恢复和移除操作，不因字段缺失让输入区崩溃。

## 视觉改动

- 工作区顶栏、侧栏、面板、快捷入口、空状态和弹层统一细边框、同心圆角和浅色阴影；选中导航使用 inset 指示条，减少多层描边。
- 页面在 980px、700px 和 420px 断点收敛内容边距、栅格和设置导航；`body` 不再用固定 1060px 最小宽度，窄屏可以进入工作区。
- 保持紫薇浅色科技影像基调、已有 Logo、真实事件与输入法/滚动/分栏约束；减少说明性文字对主操作的挤压。
