# 手机 MCP 与能力状态核验

能力组合原先只统计手动填写的工具集和 MCP，漏掉已绑定手机、通过执行环境注入的手机 MCP。因此手机实际可调用时，卡片仍显示“尚未添加工具集或 MCP 服务”。

现在从同一工作区的员工、手机绑定和已安装且附加的手机技能读取配置，并使用当前技能版本和绑定重新计算配置版本。已配置但未验证显示“待检查”；只有同一员工、电脑、Profile、手机、Bot 配置版本及控制代次的真实工具调用与进程完成记录匹配，才显示手机 MCP 状态读取成功。换绑手机、更新技能、旧版本、测试模拟结果或不完整退出记录不会沿用为成功。手动 MCP 的失败仍单独保留。

同时纠正两类状态：未读取 Goals、Heartbeat、Kanban 时显示“待检查”，读取为空才显示“需要配置”；保存但关闭的渠道和语音显示“未开启”。
