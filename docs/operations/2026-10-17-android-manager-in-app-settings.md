# 2026-10-17 Android 管理 App 0.1.2 高级设置

用户要求把模型、能力和设备绑定等常用高级设置放进 Android App，取消管理操作的浏览器外跳。App 继续使用原账号、工作区、员工、长期聊天和设备数据；Hermes 仍在绑定的常开电脑执行。

## 本版真实范围

- 模型、Provider、推理强度、人格与职责、可见范围、轮数预算、工具权限、记忆与画像上限、工作区技能、原生工具集与技能名单、外部 MCP 服务均可在 App 内读取和保存。保存完整克隆原配置，保留未编辑及未知字段；检查配置、启用、暂停新任务均由用户单独点击。暂停新任务不代表在途进程已经退出，停止仍需回聊天并等待原回执。
- 普通非 Bot 员工可调整原模型、选择已有电脑及已有 Profile。已初始化 Hermes 的运行电脑和 Profile 保持固定，界面明确“已绑定；暂不支持更换”；不绕过现有门禁，不新建员工或 Profile/HOME。
- 设备页提供电脑配对、手机入网审批、原员工与手机关联、控制端切换。员工手机控制另设开关及手机选择，复用原电脑、runtime、Profile，保留业务账号字段；普通手机关联与启用员工手机 MCP 分开展示，配置已保存不等于实际工具已加载。
- 模型与能力修改沿用原 Bot 的 `expectedRevision`；启用及暂停同时携带原控制版本。冲突保留草稿，不用最新版本自动重试覆盖；未知回执只读核对，显式重试沿用原请求参数。手机 MCP 开关复用现有后端校验。

## 权限与竞态修复

员工设置遵循现有 Owner / 管理员 / 成员权限及员工可见范围。电脑配对沿用原授权；手机审批、关联、控制端和员工手机控制设置仅 Owner / 管理员可写。成员不调用特权手机终端接口，不放宽服务端授权。

原员工手机控制配置尚未成功读取时，禁止编辑和保存；成功归属校验后才允许提交，按原请求重试也经过同一检查。慢请求、503 和从目录回读原配置均有专项回归，默认关闭不代表已知原状态。

目录和能力状态分别读取，慢请求不阻塞已加载表单；刷新保留未保存草稿和真实未确认状态。写入开始、成功和结束均使旧 Bot、手机配置及目录读取失效，写入期间不再发起这些快照读取，防止晚到旧响应回滚新配置。离开后重进同一员工，将旧保存等待态转为“尚未确认”，保留原意图并读取核对；旧页面回执不能回写或解锁新页面。
