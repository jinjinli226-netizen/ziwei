# 已有 Bot 的手机 MCP 身份传递

给现有 Hermes Bot 保存手机绑定时，入口已经验证用户角色，但手机服务调用 Bot 配置服务时丢失了认证上下文。正式文件数据库因此返回 `BOT_ACTOR_REQUIRED`；原有内存数据库及普通 Codex 员工测试没有覆盖这个组合。

API 和 MCP 路由现在将已验证的身份传入手机服务，贯穿员工查询、设备范围、配置保存、状态读取和检测派发。试运行使用真实调用者身份，保留工作区、员工可见性、设备归属和 Bot 启用检查。

手机技能配置会改变 Bot 的配置版本。向导在工具权限不足、当前版本未经检查或 Bot 未启用时，显示具体下一步和对应 Bot 设置入口；不再让用户立即提交必然被拒绝的手机检测。已有暂停状态不会被自动恢复。

回归使用真实临时文件数据库和独立 Profile 的 Hermes Bot，验证用户身份和授权设备的成功路径、匿名与越界请求拒绝、拒绝后的事务完整性，以及真实 API/MCP 路由传参。测试不启动本地监听服务。发布遵循先推 GitHub、再部署服务器的顺序；真实手机验证仅调用明确选定设备的只读状态工具。

发布前 244 项相关后端与前端测试通过，143 个源文件检查及差异格式检查通过。已在正式 HTTP 管理接口复现原 `403 / BOT_ACTOR_REQUIRED`，失败事务没有保存手机绑定。
