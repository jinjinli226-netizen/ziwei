# Provider 与员工配置交付说明

日期：2026-10-25，基线 origin/main 98dfa12，源码修复，无生产部署。

## 用户如何配置

Bot 伙伴默认列出本工作区内有权查看的全部员工，可按实际运行时筛选。Codex/未配置员工进入现有聊天或员工配置，不会自动初始化为 Hermes。Hermes 员工的「基础配置」选择服务商与对应模型，保存后填写该员工的模型 API Key；空白保留旧值，提交后清空输入。清除只影响此员工，清除后不会偷偷恢复来源认证。运行中须等待结束再更换密钥；保存新密钥会清空旧配置检查，需要重新检查再启用。

DeepSeek 官方路由固定 https://api.deepseek.com；2026-10-25 核对[官方 API 文档](https://api-docs.deepseek.com/)与[Hermes 接入说明](https://api-docs.deepseek.com/quick_start/agent_integrations/hermes/)，模型目录提供 deepseek-flash/deepseek-v4-pro。推理等级待安装版本完整验证，界面暂使用 DeepSeek 模型默认。旧 Provider 路由和未独立配置的来源认证继续兼容。自定义地址仅接受无凭据/查询参数的 HTTPS；服务商与已知模型家族冲突会拒绝保存。

API、网页、电脑客户端需要一起升级后才支持新通道；现有员工/原 Profile/HOME/记忆/会话与账号不重建。当前保护存储适配 Windows DPAPI；其他平台暂未实现安全存储，显示待同步，不降级明文。历史明确只读保留；新建与缺省权限使用已接通的完整执行能力，并保留原生资源授权和唯一平台调度。

## 分层状态

页面配置保存、电脑安全保存、当前配置检查、真实模型调用分别核对。安全存储回执不是模型调用成功；旧版本、离线、绑定变化仍待同步。未用真实Key或真实员工测试，未验收费模型调用。通用Hermes安全卡片按真实原生callback接入；Team专用PKCE设备授权尚待目标设备接入，不通过旧410入口或Vault密码替代。

实现与接口见[密钥通道](2026-10-25-bot-provider-secret-channel.md)、[安全交互](2026-10-25-bot-secure-interaction.md)、[自主工作](2026-10-25-bot-autonomy.md)、[全部员工列表](2026-10-25-all-employee-roster.md)。

## 验证边界

使用合成密钥、隔离内存数据库、受保护临时目录和命名pipe，不监听预览TCP端口、不运行设备业务。前端构建及加密/选择/隔离回归检查通过；尝试本地文件视觉预览被浏览器URL协议策略阻止，未绕过限制，未完成浏览器截图验收。真实目标电脑安装、现场外部授权、付费模型调用均待后续授权验收。
