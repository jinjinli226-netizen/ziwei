# 手机读图与 Bot 默认工具修复

截图 MCP 已回传图片，但 Hermes 会把图片缓存为 `MEDIA:` 本地路径。原新建 Bot 默认 `read_only` 且 `toolsets: []`，执行时缺少 `vision_analyze`，所以只能拿到路径，不能观察图片。

## 变更

- 新建和首次初始化 Bot 默认使用 `execute`，开启 web、browser、file、terminal、vision、skills、todo、memory、session_search、code_execution。外部服务仍需对应账号、设备绑定或服务配置。
- 创建默认值与旧配置归一化分开；既有保存配置、显式空工具列表及仅对话设置不自动改变。浏览器创建请求使用固定 v2 默认快照，旧 v1/无版本请求仍以原请求体恢复，避免重复创建。
- 手机技能更新为 1.0.1：仅得到图片路径时使用 `vision_analyze` 读取本次截图，再描述画面或确定坐标；按本次输出目录与 manifest 交付图片。截图试运行也包含此步骤。
- 实测额外发现 Bot 任务的主会话只写进 Hermes 快照，顶层动作没有会话，导致图片附件被拒收。任务创建现在先验证同员工、同工作区的权威会话，再绑定到动作；保留图片接收端的严格校验，不修改历史失败记录。

## 发布与边界

先提交并推送 GitHub，确认远端提交，再从同一提交打包部署。部署前备份数据库，失败恢复上一版代码与客户端发布元数据，保留当前业务数据；不修改数据库结构、Nginx 或手机控制服务。

本次读图工具与技能指引兼容当前 Windows 客户端。新技能版本参与手机配置指纹，上线后须用新执行刷新回执。验证只截图和读图，没有点击、输入、修改商品或发送消息。单次轮数上限自动续跑不在本次修改范围。
